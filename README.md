# Mkale FX – Member Registration

A clean member registration web app built with HTML, CSS, and vanilla JavaScript.
Focuses on form validation, DOM manipulation, and interactive UI features.

**Course:** SPI 2201 – Web Application Development I  
**Institution:** Kirinyaga University  
**Year:** 2026/2027

## Features
- Responsive registration form
- Real-time field validation
- Dynamic member list with add/remove
- Dark / Light mode toggle
- Modern card-based UI

## How to run
Just open `index.html` in your browser.
